# jobs-sg MVP 实现计划

> 本计划由 writing-plans skill 产出，本会话内 inline 执行，遵循 TDD 与 verification-before-completion。
> 步骤用 `- [ ]` 跟踪。注：本会话 apply_patch 工具不可用（与 docs/04-operations.md §6 记录同症状），文件写入改用 quoted heredoc。

**Goal:** 按 docs/05-roadmap.md Phase 1 实现可部署 MVP：Go 采集/富化/周报/web 四命令 + SQLite + 归档 + 规则层技术抽取 + fixture 回放测试 + 容器化 + k8s manifests。

**Architecture:** 单仓库多命令 Go 应用（cmd/ingest|enrich|report|web + internal/），直连 MyCareersFuture 公开 JSON API → gzip JSONL 全类目归档 → SQLite(WAL) 候选入库 → 规则层技术栈抽取（LLM 层接口化、fail-open）→ 周度指标物化 + 自包含 HTML/MD 周报 → 只读 web 托管 + Prometheus 指标。

**Tech Stack:** Go 1.26、标准库 net/http、modernc.org/sqlite（纯 Go 免 CGO）、prometheus/client_golang、多阶段 Docker、GitHub Actions。

## 任务拆分

1. 项目脚手架（go.mod/.gitignore/Makefile）
2. store：schema 迁移 + tech/ssoc 种子表
3. mcf：数据模型 + 分页客户端（限速/退避/熔断/UA）
4. mcf：gzip JSONL 归档
5. classify：is_candidate/is_swe/role_family/seniority/work_mode
6. tech：规则层技术抽取 + 别名归一
7. ingest：增量/基线/全量对账主流程
8. enrich：规则层 + LLM 接口（缓存/降级/fail-open）
9. report：weekly_metric 物化 + HTML/MD 渲染
10. web：只读托管 + /metrics + /healthz
11. fixture 回放测试（~100 条样例）
12. 容器化 + CI + deploy manifests + README/roadmap 更新
